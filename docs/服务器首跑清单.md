# 服务器首跑清单

这份清单用于你第一次把本项目搬到服务器执行训练。按顺序做，尽量不要跳步。

## 0. 进入项目目录

```bash
cd /path/to/yolodist
```

## 1. 安装依赖

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -U pip
pip install -r requirements.txt
```

## 1.1 运行预检查（建议）

```bash
python3 tools/preflight_check.py
```

## 2. 检查权重文件

请确保以下文件存在于 `weights/`：

1. `weights/yolo11n.pt`
2. `weights/teacher.pt`

说明：

- `baseline` 用 `yolo11n.pt`
- `modified_model` 用 `yolo11n.pt` 作为学生初始化权重
- `distillation` 用 `teacher.pt` 生成教师伪标签，并用 `yolo11n.pt` 初始化学生模型

## 3. 准备检测格式数据

```bash
python3 tools/prepare_mvtec_detection.py --config configs/data/mvtec_detection.toml
```

产物检查：

1. `datasets/processed/mvtec_detection/data.yaml`
2. `datasets/processed/mvtec_detection/manifest.json`

## 4. 跑 baseline 训练与评估

```bash
python3 experiments/baseline/train.py
python3 experiments/baseline/evaluate.py
```

建议补做结果摘要：

```bash
python3 tools/summarize_run.py runs/baseline/yolo11n_baseline
```

## 5. 跑 modified_model 训练与评估

```bash
python3 experiments/modified_model/train.py
python3 experiments/modified_model/evaluate.py
```

建议补做结果摘要：

```bash
python3 tools/summarize_run.py runs/modified/yolo11_student
```

## 6. 跑 distillation 训练与评估

```bash
python3 experiments/distillation/train.py
python3 experiments/distillation/evaluate.py
```

建议补做结果摘要：

```bash
python3 tools/summarize_run.py runs/distill/yolo11_student_distill
```

## 7. 首轮结果归档建议

建议把以下文件统一归档到论文实验材料目录：

1. `runs/*/*/run_manifest.json`
2. `runs/distill/yolo11_student_distill/pseudo_label_stats.json`
3. `runs/*/*/metrics_summary.json`
4. `runs/*/*/summary.md`

## 8. 常见问题快速排查

1. 报错 `Missing model weights`：
   - 检查 `weights/` 下对应 `.pt` 文件是否存在。
2. 报错 `Missing dataset yaml`：
   - 先执行第 3 步数据准备命令。
3. 评估报错找不到 `best.pt`：
   - 说明训练还没成功完成，先检查训练日志。
4. 训练显存不足：
   - 在对应 `configs/train/*.toml` 里调小 `batch`（例如从 16 改为 8 或 4）。

## 9. PPLA 与 Plain 消融命令

Plain 学生模型训练：

```bash
python3 experiments/modified_model/train.py --config configs/train/modified_model_plain.toml
```

PPLA 学生模型训练（默认）：

```bash
python3 experiments/modified_model/train.py --config configs/train/modified_model.toml
```

Plain 蒸馏：

```bash
python3 experiments/distillation/train.py --config configs/train/distillation_plain.toml
```

PPLA 蒸馏（默认）：

```bash
python3 experiments/distillation/train.py --config configs/train/distillation.toml
```
