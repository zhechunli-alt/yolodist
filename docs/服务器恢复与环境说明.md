# 服务器恢复与环境说明

这份文档用于在服务器关闭后，下一次重新启动项目时快速恢复工作环境、实验状态和运行上下文。

## 1. 项目位置

- 项目根目录：`/root/workspace/yolodist`
- Python 虚拟环境：`/root/workspace/.venv`
- 默认工作目录：

```bash
cd /root/workspace/yolodist
```

## 2. 启动环境

每次重新连接服务器后，先激活虚拟环境：

```bash
source /root/workspace/.venv/bin/activate
```

为保证本项目自带模块可导入，推荐在执行训练或评估前加上：

```bash
export PYTHONPATH=/root/workspace/yolodist/src
```

若需要跑 `YOLOX`，使用：

```bash
export PYTHONPATH=/root/workspace/yolodist/src:/root/workspace/yolodist/external/YOLOX
```

## 7. 下次启动后的推荐恢复顺序

### 方案 A：只看结果，不继续训练

```bash
cd /root/workspace/yolodist
source /root/workspace/.venv/bin/activate
```

查看 DeepPCB 外部对比结果：

```bash
cat runs/deeppcb_compare/yolov8n_eval22/metrics_summary.json
cat runs/deeppcb_compare/yolov10n_eval22/metrics_summary.json
cat runs/deeppcb_compare/ssdlite320_mobilenet_v3_large_eval2/metrics_summary.json
cat runs/deeppcb_compare/retinanet_r50_fpn_eval2/metrics_summary.json
cat runs/deeppcb_compare/fcos_r50_fpn_eval2/metrics_summary.json
```

### 方案 B：继续把 YOLOX-Nano 跑完

1. 进入项目并激活环境：

```bash
cd /root/workspace/yolodist
source /root/workspace/.venv/bin/activate
```

2. 如依赖需要重新同步：

```bash
pip install -r requirements.txt
```

3. 确认 `external/YOLOX` 存在：

```bash
ls external/YOLOX
```

若不存在，重新拉取：

```bash
git clone --depth 1 https://github.com/Megvii-BaseDetection/YOLOX external/YOLOX
```

4. 启动 YOLOX-Nano：

```bash
bash tools/run_deeppcb_yolox_nano.sh
```
