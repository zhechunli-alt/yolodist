# 前后端部署与访问说明

这份文档用于把当前仓库中的 Flask 前后端演示系统快速部署起来，并在局域网内通过其它机器访问。

## 1. 演示模型

当前默认演示模型为：

- `DeepPCB / Student-EPFA`

原因：

- 它是论文主线中最具代表性的轻量改进模型
- 相比 `student_plain` 有稳定提升
- 比 `baseline` 更适合作为“轻量部署”演示

在线推理页支持切换：

- `DeepPCB / Baseline-YOLO11n`
- `DeepPCB / Student-Plain`
- `DeepPCB / Distill-EPFA`
- `DeepPCB / Teacher`
- `PKU / Teacher`
- `DsPCBSD+ / Teacher`

另外，页面也会展示 DeepPCB 对比实验的经典模型权重资产，例如：

- `Compare / FasterRCNN-MNV3-FPN`
- `Compare / RetinaNet-R50-FPN`
- `Compare / FCOS-R50-FPN`
- `Compare / FasterRCNN-R50-FPN`

这些对比模型用于论文资产展示，不参与当前 Web 演示在线推理，避免不同框架权重在同一推理接口下混用。

## 2. 一键启动

在项目根目录执行：

```bash
source /root/workspace/.venv/bin/activate
bash tools/deploy_backend_demo.sh
```

默认会做这些事：

1. 同步标准权重别名
2. 做后端依赖与权重预检查
3. 以 `0.0.0.0:18080` 启动 Flask 服务
4. 输出日志与 PID 文件

启动成功后，日志在：

- `runs/service_logs/backend_demo.log`

PID 文件在：

- `runs/service_logs/backend_demo.pid`

停止服务：

```bash
bash tools/stop_backend_demo.sh
```

## 3. 本机访问

浏览器打开：

```text
http://127.0.0.1:18080
```

健康检查：

```bash
curl http://127.0.0.1:18080/api/v1/health
```

模型列表：

```bash
curl http://127.0.0.1:18080/api/v1/models
```

## 4. 其它机器访问

当前服务器局域网 IP：

- `10.18.207.22`

如果其它机器和这台服务器网络互通，可直接访问：

```text
http://10.18.207.22:18080
```

如果校园网有隔离，当前推荐走 Tailscale。服务器的 Tailscale 地址是：

- `100.102.5.1`

在另一台已登录同一 Tailscale 网络的机器上访问：

```text
http://100.102.5.1:18080
```

如果访问失败，按顺序检查：

1. 服务是否已启动
2. 服务器安全组或防火墙是否放行 `18080`
3. 其它机器是否和服务器在同一局域网或可达网络

## 5. 当前前后端能力

页面当前已重构为 4 个无滚动模块页：

1. `数据加载`
   - 单张图片上传
   - 文件夹批量导入
   - 样本元信息填写
2. `单模型检测`
   - 主线模型/教师模型切换
   - 单图检测
   - 检测框叠加展示
3. `多模型对比`
   - 主线模型多选对比
   - 经典对比模型资产展示
4. `记录导出`
   - 人工复核
   - 历史记录浏览
   - JSON 报告导出

## 6. 演示建议

如果用于现场演示，建议按这个顺序：

1. 页面打开后先确认右上角服务状态为“服务正常”
2. 在 `数据加载` 页上传一张典型 PCB 缺陷图片
3. 切到 `单模型检测` 页，保持默认模型 `DeepPCB / Student-EPFA`
4. 运行一次检测并截图
5. 切到 `多模型对比` 页，对比 `Student-EPFA / Baseline / Student-Plain / Distill-EPFA`
6. 如需展示论文资产，再截图右侧的经典对比模型资产区
7. 最后在 `记录导出` 页填写复核意见并导出 JSON 报告

## 7. 注意事项

1. 当前前后端是演示部署，使用 Flask 自带服务，适合论文展示和局域网访问，不是生产级部署
2. 如果后续需要公网长期运行，建议换成：
   - `gunicorn + nginx`
   - 或单独拆前后端服务
3. 当前页面模板已经改成 PCB 质检语境，但数据库表名仍保留了早期 `review_notes` 等字段名，这不影响实际使用
